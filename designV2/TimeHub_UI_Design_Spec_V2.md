## 1. V2 审查结论与修正清单

对 V1 逐一复审后发现 6 处不符合专业交付标准的问题，全部修正：

| # | 问题（V1） | 严重度 | V2 修正 |
|---|---|---|---|
| 1 | 周视图 11 个时间轴事件块全部同色（统一 #BCD0F7 蓝底 + 彩色左边框），整体观感像渲染缺陷而非设计意图；月视图已按类别着色，周视图色彩语言断裂 | ★★★ | 事件块按日历类别着色：15% alpha tint 底 + 同色系 26% 边框 + 深化 25% 的类别色标题（对齐 Google Calendar / Outlook 惯例） |
| 2 | 事件标题在 tint 底上用纯黑灰（--text-1），色彩语义未传达 | ★★★ | 标题统一用 `shade(cat, -25%)` 深化类别色；时间保持 --text-2 次要层级 |
| 3 | "今天"定位弱：月视图今天格只有数字圆点，周视图今天列无任何高亮 | ★★☆ | 月视图今天格整格 `--accent-subtle` 淡蓝背景；周视图今天列 5% 蓝 tint 背景列高亮 |
| 4 | 月视图事件 chip 时间标签 --text-3（#8A92A5）在 tint 底上对比度不足（WCAG 4.5:1 边缘） | ★★☆ | 时间标签升为 --text-2（#5A6273） |
| 5 | `.w-ev` CSS 存在重复声明块（box-shadow/overflow 各两次）；蓝色边框 `rgba(46,107,230,.18)` 硬编码在所有颜色事件上（橙事件配蓝边） | ★☆☆ | 合并为单一声明块；边框颜色改由 JS 按类别注入 `hex+42` |
| 6 | 页尾残留 3 个调试色块 div（固定视口右上角显示 "E8F0FE"/"rgb" 色样）与 1 段断裂注释 | ★☆☆ | 全部删除 |

**未改动项（V1 已达标）**：Design Token 体系（颜色/间距/圆角/阴影/字号）、侧边栏与迷你月历、检查器面板、四象限、快速面板、新建日程模态、设置页、桌面挂件玻璃效果、空/错状态、暗色主题 token、URL hash 路由与缩放。

## 2. 事件色彩语言（V2 核心改进）

统一"类别色 → 三层表达"规则，月视图与周视图完全一致：

| 层 | 表达 | 作用 |
|---|---|---|
| 背景 | 类别色 15% alpha tint（`hex + '26'`） | 面积色块，快速扫视分类 |
| 边框 | 类别色 26% alpha（`hex + '42'`） | 锁定事件轮廓 |
| 标题 | 类别色深化 25%（`shade(hex, -0.25)`） | 保证 tint 底上 ≥4.5:1 对比度 |

类别色板（light）：

| 类别 | Hex | 深化标题色 |
|---|---|---|
| 工作 | `#2E6BE6` | `#2350AD` |
| 外部沟通 | `#C77700` | `#955900` |
| 个人/健康 | `#0E9F6E` | `#0B7753` |
| 家庭 | `#DB2777` | `#A41D59` |
| 设计 | `#7C4DFF` | `#5D3ABF` |

着色由两段 JS 驱动（无手写散落色值）：
- 月视图：`buildMonth()` 内 `fillBg()` / `deepTxt()`
- 周视图：DOM 就绪后遍历 `.w-ev[data-c]`，按 `COLOR_HEX` 映射注入行内样式
