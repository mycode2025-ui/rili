# TimeHub V2 UI 偏差清单

基准：`designV2/mockup.html` 与 `designV2/shots/s1-s9.png`。产品窗口按原型内部画布 `1280 × 820` 实现；参考 PNG 的 `1560 × 980` 还包含原型展示页的黑色外框和标题，外框不属于产品界面。

## 已验证一致项

- 设计 Token 已集中到 `ui/theme.slint`，亮色和暗色均来自原型变量。
- `ui/` 中除主题文件外，硬编码 `#RRGGBB`、`rgb()`、`rgba()` 扫描结果为 0。
- 49 个图标均由原型 SVG sprite 提取，不使用 Emoji、字体图标或乱码替代符号。
- s1-s9 均有可构建 Slint 组件；月/周/今天/待办、快速面板、新建日程、设置、桌面挂件和状态页已实现。
- 事件颜色规则已实现为类别色 15% tint 背景、类别色边框、类别色深化 25% 标题色。
- 主窗口最小化、最大化、关闭到托盘可用；亮色、暗色、跟随系统和强调色选择可持久化并同步到独立窗口。

## 尚存偏差

| 编号 | 位置 | 设计稿值 | 当前实现 | 原因 / 后续决策 |
| --- | --- | --- | --- | --- |
| D-01 | s8 桌面挂件卡片 | CSS `backdrop-filter: blur(...)` 的真实桌面背景毛玻璃 | 使用原型 Token 的半透明背景、边框、阴影及固定渐变桌面底图 | Slint 1.17 没有等价的跨窗口桌面背景采样与 backdrop blur。需要 Windows Acrylic/DWM、macOS NSVisualEffectView 分平台原生接入，禁止用模糊截图冒充。 |
| D-02 | s5 托盘快速面板 | 锚定任务栏托盘区域弹出，失焦自动收起 | 已实现独立无边框 `460 × 640` 快速面板和托盘点击打开；位置暂由窗口系统决定 | 精确锚定与失焦收起需要 Windows 工作区/托盘坐标和原生窗口消息接入，列入任务栏增强模块。 |
| D-03 | 主窗口无边框标题栏 | 标题栏空白区域可拖动窗口 | 最小化、最大化和关闭按钮已接通；空白区拖动尚未接入 | Slint 公共 API 没有启动原生窗口拖动的方法；Windows 需通过 HWND 发送非客户区拖动消息，macOS 需对应原生实现。 |

以上偏差均未静默降级；后续实现原生平台层后逐项关闭。
