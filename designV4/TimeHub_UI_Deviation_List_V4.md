# TimeHub UI V4 偏差清单

## 已确认偏差

| 位置 | 设计稿值 | 实现值 | 原因 / 决策 |
|---|---|---|---|
| s5 快速面板：日程或待办为空 | V4 仅给出有数据状态，未定义空状态尺寸 | 每个空状态高 56px，使用 `Theme.bg-surface-2`、`Theme.border-subtle`、`Theme.r-md`，文字居中 | 避免无数据时把两个区域各拉伸到半屏而形成大片留白；颜色、圆角、描边全部复用 V4 Token。 |
| 设置页窄窗口长说明 | V4 以宽屏为基准，未定义窄窗口截断规则 | 保持单行并使用 `overflow: elide`；系统时钟说明精简为“保留原生时钟；单击右下角时间打开 TimeHub” | 防止 16px 字号和窄窗口下文字越过右侧操作控件。 |

## 无偏差项

- s3 状态栏绿点与文字：按 28px 状态栏垂直居中，间距 8px。
- s3 左侧“今日概览”：标题 20px，三张统计卡各 66px、间距 8px。
- s5 底部导航：五等分容器，按钮 44×34px，只显示图标，文字保留为无障碍名称。
- 新建日程：主窗口、快速面板、月历挂件和今日日程挂件统一调用同一个完整编辑器；保存失败保留弹窗并显示行内错误。
- s8 六款独立桌面挂件：日程类挂件的“+”调用完整日程编辑器；倒数日、时钟提醒、专注计时和待办仍使用各自对象类型的专用新建面板。
- 字体系统：主窗口、设置、弹窗、快速面板和全部独立挂件统一使用 `Theme.font-family` 与字号 Token，无裸 `px` 字号残留。
- 设置页宽屏布局：信息列自适应拉伸，主题卡、强调色、字号、密度与开关统一右对齐；窄屏按最小宽度收缩。
- 标题栏全局搜索：常驻入口与 `Ctrl+K` 均打开同一搜索弹层，支持实时查询与结果跳转，不再占用独立视图页。
- 强调色选择：选中态使用 28px 外环，内部色块始终保持 22px，不再因内描边产生缩小错觉。
- 设置归类：任务栏时钟入口移入“日历”，外观页只保留主题、强调色、字号、密度和减淡动效。
- 通知验证：改名为“验证系统通知 / 发送示例”，提示条 4 秒自动消失；关闭系统通知时不会误发。
- 更多菜单：只保留快速面板、桌面挂件、日历订阅和设置；开发验收用“状态与错误总览”已从生产构建移除。
- 无边框窗口及独立挂件拖动区域保持系统默认箭头光标，拖动回调与系统窗口拖动逻辑保持不变。
