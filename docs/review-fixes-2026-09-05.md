# TimeHub 审查整改（2026-09-05）

## 本轮范围

保留工具页四组上下平铺：时间工具、日期与生活、日程助手、日历同步。没有改回横向页签，没有删除用户日程，也没有提交或推送代码。

## 已实现

- 便签：已有便签允许保存空内容；真实数据库结果驱动保存反馈；失败草稿阻止切换便签，并在切换主页面时保留。新建空草稿不立即落库。正文支持滚动、多行和 Unicode。编辑工具栏作用于最近聚焦的标题或正文；选中标记左对齐，仅保留一处保存状态。
- 今天：下一场/进行中按当前时间判断，全天事项不抢占下一场；窄窗口纵向排列、内容可滚动，空列表压缩，倒数日多条时横向滚动。移除侧栏重复的今日概览，避免低高度窗口溢出。
- 删除：长期记录与习惯增加明确确认；习惯及历史打卡删除使用事务，失败时不会只删掉历史。
- 日期：区分日期间隔和日期推算，常驻字段标签；显示计数口径和节假日覆盖年份，超大推算数值返回错误。
- 同步：单连接同步、编辑名称/专用密码、来源日历及条数、最近成功时间、删除影响范围、可复制详情；失败不抹除最近成功时间。校验失败不清空密码，也不留下空分类日历；同步期间阻止重复操作。错误隐藏完整 URL，避免复制订阅令牌。
- 视觉：深色日程标题使用正文颜色，提高辅助文字对比度；移除固定个人头像；图标补充操作名称；待办补键盘焦点入口；主侧栏可滚动。
- 测试：新增持久化、删除事务、错误脱敏、连接编辑、便签实际按键/自动保存测试；视觉脚本加入主窗口四页、明暗主题、四档 DPI。原生冒烟使用独立测试数据，拒绝强制关闭用户实例。
