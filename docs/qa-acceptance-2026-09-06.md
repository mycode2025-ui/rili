# TimeHub 系统验收记录（2026-09-06）

## 首轮结论与测试边界（修复前，保留失败证据）

**不通过发布验收。不能宣称“全部功能都没有问题”。** 现有自动化套件通过，但新增跨功能验收发现真实缺陷。

- 基线：Git `8203d6e`，叠加本地 `FocusTouchArea` 点击区域修正。Windows、Asia/Shanghai、Slint 1.17.1，主窗口最低支持 960×640。
- 原有 `cargo test --all-targets --quiet`：54 项通过；格式检查和 Clippy 零警告通过。
- 原有视觉比较：88 张通过，未更新基线。视觉比较只能证明没有偏离基线，不能证明基线合理或按钮可操作。
- 新增 `system_acceptance`：8 项，2 通过、6 失败；`network_acceptance`：1 项失败，内含两个独立缺陷断言结果。
- 新增 `app_navigation_acceptance`：1 项失败，失败点仅为搜索 Esc；在该断言前，7 个主页面导航、新建日程打开、搜索打开、点击外部关闭搜索、设置打开均已逐项通过。
- 合计已执行 64 个自动化测试函数：56 通过、8 失败；对应 9 个逻辑/交互缺陷，另有 1 个课程表布局缺陷。一个测试函数含多个步骤，不能把函数数当成功能覆盖率。
- 补充渲染月/周/三日/年/待办/课程表 6 个视图。日历类预览缺少完整运行期数据，不能把空白/零日期判为产品故障；课程表固定工具栏和网格裁切可独立确认。
- 测试新建临时 SQLite 数据库，含重启读回和全新库恢复。模拟 HTTP 只访问 `127.0.0.1`，未使用任何真实账号密码。没有修改真实日程/便签，没有提交推送，没有修正本轮发现的业务缺陷。
- Computer Use 能读取应用可访问性树，但截图与目标窗口不一致，激活失败；重新定位后再试仍报 `failed to activate captured window`。按技能恢复规则停止 Windows 输入。**真实窗口逐按钮验收未完成。** 上一轮原生冒烟结果不能替代本轮逐按钮验收。
