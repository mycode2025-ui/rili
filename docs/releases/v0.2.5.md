# TimeHub v0.2.5

- 修复 Outlook/ICS 隔周重复与单次改期、取消的解析和同步；避免重复生成会议。
- 临时网络错误增加有限重试，并保留已有日程；后台同步结果及时刷新界面。
- 修复设置页 Esc 关闭，缩小搜索面板并按结果数量调整高度。
- 统一同步按钮对齐，压缩桌面卡片面板和关于页多余留白。
- 桌面卡片按钮增加简洁底座及悬停反馈，保留原有拖动范围。

便携版：下载 TimeHub.exe，退出旧程序后替换。已有本地配置与日历数据保留。
程序启动和“设置 → 关于 → 检查更新”会查询发布源；下载和替换需要用户确认，不会后台静默安装。

本地验证：100 张视觉回归、键盘焦点交互、原生双显示器冒烟及到点提醒测试。
