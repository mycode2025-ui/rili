# 月历点击失效回归

根因：用无根类型的 `FocusTouchArea` 替换原生 `TouchArea` 后，没有继承原生的父容器填充尺寸。未显式设置尺寸的调用处实际点击区域为 0×0，标签可见但鼠标无法命中。

修正：在公共组件设置左上角原点和 100% 宽高，不改动日程数据、同步逻辑或页面布局。

影响范围检查：月历日期与日程标签、迷你日历、主界面新建/搜索/日历显示开关/通知入口、待办和卡片管理等使用同一组件的入口。已有显式尺寸的入口保留原尺寸。

新增 `calendar_click_regression` 隔离测试，直接派发鼠标按下/松开事件，验证默认尺寸、标签日程 ID 和日期传递、标签与日期背景不串触发、日期选择、公共组件鼠标/空格操作和禁用状态。旧代码的默认尺寸断言先复现失败（0 而非 300）。此测试加入 CI。

88 张原有视觉基线比较通过，未更新基线；尺寸探针修复后为 300×60，与原生 TouchArea 一致。

修复后完整 49 项测试通过（43 核心、4 数据安全、1 便签、1 点击交互）；格式检查、Clippy 零警告和 Release 构建通过。
