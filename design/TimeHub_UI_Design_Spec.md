# TimeHub 桌面日历 — UI 高保真原型设计规格

> 配套文件：`mockup.html`（单文件 HTML，0 外部依赖，9 屏内联可切换）
> 演示时间锚点：2026-08-31 周一 22:53

---

## 1. 设计目标与原则

| 原则 | 落点 |
|---|---|
| **零依赖单文件** | `mockup.html` 独立可双击运行，inline SVG icon sprite + system font stack |
| **8px 栅格 + 4 因子 token** | `--s-1..--s-8` 间距系统；圆角/字号/阴影同源 |
| **亮/暗双主题** | `:root` + `html[data-theme="dark"]` 两套 token，主题切换零刷新 |
| **三档密度** | 紧凑 / 标准 / 宽松，影响行高、卡片 padding、字号缩放 |
| **响应式** | 视口 100% / 78% / 62% 三档缩放，框架内 Liquid layout |
| **微动效有控** | `prefers-reduced-motion` + 设置项可关，避免 60+Hz 无意义跳动 |

## 3. 设计 Token 系统

### 3.1 颜色（light → dark）

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#F7F8FB` | `#0B1020` | 应用主背景 |
| `--bg-surface` | `#FFFFFF` | `#161B2E` | 卡片表面 |
| `--bg-surface-2` | `#F1F4FA` | `#1E2A45` | 次级表面（off-hour 网格） |
| `--text-1` | `#0B1020` | `#E8ECF8` | 主文本 |
| `--text-2` | `#5B6478` | `#A0AAC4` | 次文本（事件时间/备注） |
| `--text-3` | `#8C95A8` | `#6E7894` | 辅助文本（时间轴 HH:MM） |
| `--border` | `#E6E9F0` | `#2A3354` | 一级边框 |
| `--border-subtle` | `#EEF1F7` | `#1F2540` | 网格内分隔线 |
| `--accent` | `#2E6BE6` | `#6C9BFF` | 强调色（按钮/选中） |
| `--accent-hover` | `#1F5BD1` | `#85ACFF` | 强调色 hover |
| `--accent-subtle` | `#E8F0FE` | `#1E2A45` | 选中态低饱和背景 |
| `--danger` | `#D93A49` | `#FF5C6B` | 当前时间线 / 过期待办 |
| `--on-accent` | `#FFFFFF` | `#0B1020` | 强调色之上的文本 |

## 4. 关键交互模式

| 模式 | 落点 |
|---|---|
| **全局搜索** | 顶栏 `Ctrl K` 唤起，输入即解析（标题/时间/地点 chip 自动补） |
| **URL hash 路由** | `#s1`–`#s9` 直达任一屏；浏览器前进/后退键有效 |
| **主题热切换** | 顶栏"浅/深"切换，0 闪烁（仅替换 CSS 变量） |
| **缩放** | 顶栏 100% / 78% / 62% 三档（`transform: scale` on `.frame`） |
| **自然语言新建** | s6 输入框 `明天 15:00 研发周会` → chip 解析：标题/时间/地点/状态 |
| **快速面板** | s5 460×820 托盘形态，5 个底部 tab（日/待/节/倒/设） |
| **桌面挂件** | s8 3 风格，悬浮于桌面，玻璃模糊 + 锁定置顶 |
| **拖拽** | s4 四象限间任务拖拽（HTML5 DnD 框架已就位，业务逻辑待接） |

## 5. 周视图实现要点（已修复）

> 历史 bug：`.w-grid` 用 `transform:translateY(-480px)` 把网格上移以居中"今天"时段，但内部 `.w-events` 容器未同步平移，导致 11 个时间轴事件渲染在屏幕 y=-440 被 `.w-scroll` 裁掉。

| 元素 | 修正 |
|---|---|
| `.w-events` | 加 `transform:translateY(480px)` 抵消父级 -480，让事件 top 基准与 wkRows 同步到屏幕 y=0 |
| 当前时间线 `.nowline` | top 计算由"距 06:00"改为"距 00:00"再减 480：`top = h*60*40/60 - 480`，与 wkRows row 22（22:00）底部对齐 |
| 事件块 `.w-ev` | `<b>标题</b>时间` → `.w-ev b{color:var(--text-1)}` + `.w-ev .in{color:var(--text-2)}` 拉开主次层级 |
| 事件底色 | `var(--accent-subtle)` (#E8F0FE) → `#BCD0F7`，配合 1px 蓝边 + `--shadow-1` 在白底上清晰可读 |
