# TimeHub V3 顶部控件与全屏实现核对

核对基准：`designV3/mockup.html`、`designV3/TimeHub_UI_Design_Spec_V3.md`、`designV3/shots/s1–s10*.png`。

## 顶部控件结论

原型顶部栏共有 15 个控件。源码将其定义为设计稿画面导航与预览工具，不属于 TimeHub 产品界面，因此正式应用不复制这条顶部栏；其指向的产品界面和主题状态必须分别实现。

| 原型控件 | 原型行为 | 产品实现 | 核对结果 |
| --- | --- | --- | --- |
| 1 月视图 | `go("s1")` | `AppWindow`，`view-mode = 0`，42 格月网格、事件 chip、侧栏与详情栏 | 已实现，亮/暗已截图 |
| 2 周视图 | `go("s2")` | `WeekView`，`view-mode = 1`，全天区、时间轴、重叠事件与当前时间线 | 已实现，亮/暗已截图 |

| 挂件 | 数据与状态 | 已接入交互 |

## 主题核对

- `ui/theme.slint` 是 Slint UI 唯一允许出现字面颜色的文件。
- UI 层硬编码色值扫描结果：0 项。
- V3 亮/暗语义 Token、挂件玻璃态 Token、第 10 屏固定对照 Token 已集中定义。
- 类别颜色不随全局亮/暗主题替换；事件背景、边框和标题仍由同一类别基色派生。
- `s1–s10` 共 20 张实现截图位于 `designV3/implementation-shots/`。

## 偏差清单

| 位置 | 设计稿值 | 实现值 | 原因 / 决策状态 |
| --- | --- | --- | --- |
| s8 挂件玻璃背景 | CSS `backdrop-filter: blur(14px)` | 半透明 Token、渐变壁纸、边框和阴影；无背景采样模糊 | Slint 1.17 原生组件没有与 CSS `backdrop-filter` 等价的跨平台属性。当前为显式替代，待确认是否接受平台专用模糊 API。 |
| s8 倒数日规格文字与实际画布 | 规格卡写 M / 252px，画布 CSS `.wgt-cd` 写 304px | 304px | 设计稿内部冲突；按可见画布和实际 CSS 结构实现。 |
| s8 今日待办高度 | 原型为内容自适应，设计画布底部会裁切添加按钮边缘 | 226px，按钮完整位于 568px 桌面内 | 保证真实产品按钮可点击；高度比原型可见卡片多 8px，等待设计确认。 |
| s10 展示方式 | 原型长页包含顶部预览导航和说明区 | 独立 1280×1050 验收窗口，只包含主题对照内容 | 顶部栏是原型工具而非产品 UI；不写入正式窗口。 |
| s6 提醒第四项 | `当天 09:00`（绝对时刻提醒） | `提前 1 天`（相对偏移 1440 分钟） | 当前事件模型只存 RFC 风格相对提醒偏移；绝对时刻提醒需要新增触发时间类型。已明确展示为实际语义，没有伪装成设计稿文案。 |
| s6 更多选项 | 地点 / 备注 / 标签 / 时区 | 本轮持久化备注；地点、标签、时区仍由扩展事件字段承载计划处理 | 设计稿未定义字段编辑器展开后的尺寸和控件；未静默伪造输入，待补齐数据模型与设计确认。 |
| s7 非“外观”分区正文 | 原型只给出左侧入口，没有对应正文设计 | 使用 V3 Token 构建日历、通知、同步、隐私、快捷键、数据、关于的功能面板 | 设计稿未定义；为消除死按钮提供同构功能面板，等待设计终审。 |
| Outlook 登录 / 联系人导入 / 更新检查 | 原型只定义入口和状态 | 路由到集成配置或明确提示需要系统授权/更新服务地址 | 外部 OAuth、系统通讯录权限和发布服务不在本地 UI 可单独完成的边界内；按钮有明确结果，不伪报成功。 |
| CSS `--r-pill` 在 Slint 中的映射 | `999px`，浏览器按控件短边的一半钳制 | 固定高度控件使用高度的一半（8→4、18→9、20→10、22→11、24→12、26→13、30→15px） | Slint 1.17 不具备 CSS 相同的超大圆角钳制语义；直接传入 999px 会渲染成长椭圆。当前实现与浏览器最终可见几何等价。 |
| 底部操作提示条 | 设计稿未定义 | 300×38px，`--r-lg` 12px 圆角矩形 | 避免提示条与搜索框/标签混成胶囊语义；按用户终审意见统一为普通浮层圆角。 |
| Windows 六个独立桌面挂件的任务栏行为 | 原型未定义系统窗口样式 | 使用 Winit `set_skip_taskbar(true)` 调用 `ITaskbarList::DeleteTab`，同时设置 `WS_EX_TOOLWINDOW` 并移除 `WS_EX_APPWINDOW` | 用户终审明确挂件不应成为六个独立任务栏程序；主程序仍保留唯一任务栏入口。实机审计六窗均为 `TOOLWINDOW=True / APPWINDOW=False`。 |
| 六个桌面挂件的独立新建 | V3 s8 仅在“今日待办”画出添加按钮，其余挂件未定义新建层 | 六窗标题栏统一增加 `+`；月历/日程/倒数日/时钟提醒/专注任务/今日待办均在挂件内完成输入、校验、保存和原地刷新 | 用户终审明确补充。新建层使用 V3 Token 和 SVG 加号，不拉起主窗口；输入错误留在当前挂件内显示。 |
