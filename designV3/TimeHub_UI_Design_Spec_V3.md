## 二、桌面挂件系统（V3 重点）

### 2.1 双主题磨砂形态

| 维度 | 暗色磨砂 (.desk.dk) | 亮色磨砂 (.desk.lt) |
|---|---|---|
| 背景 | `rgba(28,31,39,.74)` | `rgba(255,255,255,.80)` |
| 描边 | `rgba(255,255,255,.12)` | `rgba(255,255,255,.85)` |
| 阴影 | `0 16px 32px rgba(0,0,0,.45)` | `0 16px 32px rgba(31,42,80,.22)` |
| 主文字 | `#E8EAF0` | `#1B1F2A` |
| 次文字 | `#A2A9BA` | `#5A6273` |
| 强调色 | `#6C9BFF` | `#2E6BE6` |
| 背景光晕 | 蓝/橙/绿 径向渐变（暗调） | 白/橙/蓝 径向渐变（亮调） |

实现：所有挂件内部颜色用 `--wg-*` CSS 变量，外层 `.desk.dk / .desk.lt` 注入变量值，**同一份挂件 HTML 在两种壁纸下零修改切换**。

### 2.2 6 款挂件

| 编号 | 挂件 | 默认尺寸 | 核心功能 |
|---|---|---|---|
| W1 | 月历挂件 | L·304 | 本地日历汇总 · 事件日圆点 · 点击跳转主窗口 |
| W2 | 今日日程 | L·304 | 最多 4 条 · **已结束/进行中/未开始三态** · 底部入口 |
| W3 | 倒数日 | M·252 | 置顶倒数日 · 农历支持 · ≤7 天数字块转红 |
| W4 | 时钟挂件 | L·304 | 42px 超细时间 + 秒 · 农历 · 今日进度条 |
| W5 | 专注计时 | M·252 | conic 进度环 · 轮次圆点 · 暂停/完成/继续 · 结束写入日历 |
| W6 | 今日待办 | M·252 | 进度条 + 百分比 · 标签（家庭/习惯）· 虚线快速添加 |

每款挂件头部含：图标 + 标题 + 弹簧 + 图钉（置顶）+ 设置。

### 2.3 事件三态规则（V2 沿用并扩展到挂件）

- **已结束**：`.e.done` — 整行 opacity .55 + 标题 line-through
- **进行中**：`.e.now` — outline 1.5px solid 强调色 + 标题后缀 "· 进行中"
- **未开始**：默认样式
- 专注计时、待办打卡分别用进度环 / 进度条传达状态

## 三、主题对照屏（s10 · 新增）

### 3.1 布局

- 标题 + 描述
- 双面板 `.theme-duo`（grid 1:1，gap 20）：
  - 左侧 `.theme-demo.lt`（内嵌亮色 Token）
  - 右侧 `.theme-demo.dk`（内嵌暗色 Token）
- 两行 Token 色板（每行 10 个 swatch）：
  - 浅色主题 Token：bg-app / bg-surface / text-1 / accent / danger / success / warning / c-purple / c-pink / c-cyan
  - 深色主题 Token：同上对应暗值

### 3.2 设计意图

- 同一界面片段（月历 + 工具栏 + 事件 chips）在亮/暗两主题下的**逐元素对照**
- 面板内嵌 `--td-*` 主题变量，**不随全局 `data-theme` 切换**——保证对照展示稳定
- 色板采用**固定白色参考卡**（不跟主题变色），让深色色块在暗色页面下也清晰可读，这是 Token 对照本就该独立于主题

## 五、技术约束（与 V2 一致）

- 单文件 HTML · 0 外部依赖 · 内联 SVG sprite
- 8px 栅格 · 圆角阶梯 r-sm/md/lg/xl/pill
- 阴影三档 shadow-1/2/3
- URL hash 导航 `#s1`–`#s10` · 主题切换 URL 参数 `?theme=dark`
- 所有颜色取自 Token，**禁止裸写色值**（仅色板 swatch 的展示色是设计意图的例外）
